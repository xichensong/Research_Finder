# Profile

Fill this in and save it (e.g. `my_profile.md`). Delete any section that
doesn't apply. This file stays local — it's read from disk and sent to the
model as context, nothing else happens to it. Keep it out of anywhere you'd
push to a public git repo, since it's personal data in plain text.

The example below (marked EXAMPLE) shows the level of detail that's
actually useful — vague entries ("good at coding") give the agent nothing
to ground next steps in; specific entries ("built X using Y, currently
learning Z") do.
